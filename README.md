# 5-STAR BUSINESS ACADEMY

## Описание проекта

Адаптивная вёрстка лендинга услуг по улучшению бизнеса.
Сайт находится по адресу — [salesstandard.ru](https://salesstandard.ru/)

## Технологии

- HTML5, Nunjucks, семантическая вёрстка
- CSS3, SCSS, Flexbox, CSS Grid
- JavaScript / jQuery
- Gulp
- BEM

## Возможности

- Адаптивная вёрстка: mobile, tablet, desktop
- Кроссбраузерность: Chrome, Firefox, Safari, Edge
- Слайдеры, модальные окна, табы, аккордеоны
- Плавная прокрутка по якорным ссылкам
- Валидация форм
- Анимации и интерактивные элементы
- Оптимизация изображений

## Начало работы

Перед запуском убедитесь, что у вас установлен [Node.js](https://nodejs.org).

### Шаг 1: Установка зависимостей

Клонируйте репозиторий и установите все необходимые модули:
```bash
npm i
```

### Шаг 2: Запуск в режиме разработки (Development)

Для локального просмотра и тестирования проекта запустите команду:
```bash
npm run dev
```
Откроется локальный сервер, обычно по адресу:

```text
http://localhost:3000
```

## Сборка для продакшена

Чтобы получить оптимизированную версию лендинга, готовую к деплою на реальный хостинг, выполните команду сборки:
```bash
npm run build
```
После этого все файлы будут находиться в папке:
```text
build/
```

## Структура проекта

### Исходный код (`src/`)
*   **`src/scss/`**: Стили проекта (SCSS). Здесь хранятся основные стили, которые компилируются в конечный CSS-файл.
*   **`src/js/`**: JavaScript модули и скрипты.
*   **`src/html/`**: Вспомогательные HTML-шаблоны или компоненты.
*   **`src/img/`**: Изображения, фоновые картинки и медиафайлы.
*   **`src/fonts/`**: Шрифты, используемые в проекте.
*   **`src/favicon/`**: Иконка, отображаемая во вкладке браузера

### ⚙️ Конфигурация проекта (Root Level)
Эти файлы управляют сборкой, зависимостями и общим поведением проекта.
*   **`package.json`**: Определяет метаданные проекта, скрипты запуска (`npm run dev`, `npm run build`) и список всех внешних библиотек (зависимости).
*   **`gulpfile.js`**: Файл конфигурации для задач сборки проекта с помощью Gulp. Он определяет последовательность шагов компиляции стилей, JavaScript и минификации ресурсов.
*   **`gulp/`**: Конфигурационные файлы для сборки проекта (например, задачи Gulp).
